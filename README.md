# امداد باتری چابهار — نسخهٔ آمادهٔ دیپلوی (بدون نیاز به نصب یا build)

فایل `index.html` کامل و آماده است — روی کامپیوتر هم با دابل‌کلیک باز می‌شود، روی اینترنت هم.

## انتشار روی Vercel (۳ دقیقه)
1. محتویات این پوشه را در یک ریپوی گیت‌هاب آپلود کنید (۴ فایل: `index.html`، `vercel.json`، `api/sms.js`، `README.md` — دقت کنید `index.html` در ریشه باشد، نه داخل پوشه).
2. در vercel.com با حساب گیت‌هاب وارد شوید ← **Add New → Project** ← **Import** ریپو.
3. اگر Framework Preset پرسید، **Other** را انتخاب کنید (فایل `vercel.json` خودش همه را تنظیم کرده) — چیزی عوض نکنید ← **Deploy**.
4. ۱ دقیقه بعد سایت زنده است: `نام-پروژه.vercel.app`

⚠️ نکته مهم: در گیت‌هاب فقط همین ۴ فایل باشند. اگر قبلاً فایل‌های دیگری (مثل package.json یا پوشه src) آپلود کرده‌اید، همه را حذف کنید — همان‌ها باعث خطای build شدند.

## پنل‌ها
| پنل | آدرس | رمز پیش‌فرض |
|---|---|---|
| مدیر (سفارش، فیش، گفتگو، اعلان صوتی) | `/owner` | `123654` |
| ادمین (تنظیمات کامل) | `/admin/login` | `123654` |
| امدادگر | `/tech/login` | `1234` |

آدرس پنل‌ها مثلاً: `chabahar-battery.vercel.app/owner`

## اعلان‌ها
- 🔔 اعلان رایگان ntfy بدون هیچ تنظیمی کار می‌کند — شناسه را از پنل ادمین ← تنظیمات ← «ساخت» بسازید و در اپ ntfy گوشی عضو شوید. دکمهٔ «ارسال اعلان آزمایشی» هم همان‌جاست.
- 💬 پیامک (اختیاری): فایل `api/sms.js` آمادهٔ سرور است — فقط کلید `SMS_API_KEY` را در Vercel بگذارید (راهنما داخل خود فایل است).
