# امداد باتری چابهار — نسخهٔ آمادهٔ دیپلوی (بدون نیاز به نصب یا build)

فایل `index.html` کامل و آماده است — روی کامپیوتر با دابل‌کلیک باز می‌شود، روی اینترنت هم.

## فایل‌ها (همین ۵ تا کافی است — چیزی اضافه نکنید)
- `index.html` — کل سایت
- `vercel.json` — تنظیم ورسل (بدون build)
- `api/state.js` — همگام‌سازی زندهٔ دستگاه‌ها (موبایل مشتری ↔ لپ‌تاپ مدیر ↔ پنل ادمین)
- `api/sms.js` — پیامک کاوه‌نگار (اختیاری)
- `README.md` — همین راهنما

## انتشار روی Vercel (۳ دقیقه)
1. محتویات این پوشه را در ریپوی گیت‌هاب آپلود کنید (`index.html` در ریشه باشد).
2. vercel.com ← Add New ← Project ← Import ریپو ← Framework اگر پرسید: **Other** ← Deploy.
3. سایت زنده: `نام-پروژه.vercel.app`

## ⭐ روشن کردن همگام‌سازی (مهم — ۲ دقیقه، رایگان)
تا این را نکنید، هر دستگاه داده‌هایش جدا ذخیره می‌شود (سفارش گوشی در لپ‌تاپ دیده نمی‌شود):
1. داشبورد Vercel ← پروژه ← تب **Storage** ← **Create Database** ← **KV** ← Create
2. **Connect to Project** ← انتخاب پروژه ← Connect
3. تب **Deployments** ← سه‌نقطهٔ دیپلوی آخر ← **Redeploy**
4. تمام — بالای پنل مدیر سبز می‌نویسد «همگام با همهٔ دستگاه‌ها». از این لحظه سفارشِ هر گوشی در چند ثانیه روی همهٔ پنل‌ها می‌افتد و پیام‌ها دوطرفه است.

## اعلان‌ها
- 🔔 اعلان رایگان ntfy بدون تنظیمات کار می‌کند — شناسه را از پنل ادمین ← تنظیمات بسازید و دکمهٔ «ارسال اعلان آزمایشی» را بزنید.
- 💬 پیامک (اختیاری): کلید `SMS_API_KEY` کاوه‌نگار را در Environment Variables ورسل بگذارید (راهنما داخل api/sms.js).
